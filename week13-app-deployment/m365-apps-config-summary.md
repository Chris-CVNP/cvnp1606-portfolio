Microsoft 365 Apps Configuration Summary
ACME should be using the Monthly Enterprise Channel for Microsoft 365 Apps. The monthly enterprise channel has the benefit of providing all of your updates (feature, security and non-security) one time per month on Patch Tuesday. This will provide your Help Desk a predictability they would otherwise not have along with less surprise when compared to the current channel. Semi-annual enterprise channel was discontinued as a valid choice for a new deployment beginning with Microsoft's unification of this channel into Monthly Enterprise Channel in the Version 2606 release in July 2026. As depicted by Matt’s evidence set, Monthly Enterprise Channel was chosen in the Add Microsoft 365 Apps Wizard.
After selecting a channel within Intune, the devices receive updates on their own from the Office Content Delivery Network according to their respective channel schedules. A check and enforcement occurs regarding the previously selected channel every time policy refreshes. When necessary for a particular group to operate under a different channel or update schedule, an administrator can create another settings catalog profile under Microsoft Office 2016 Machine, Updates and assign it to that specific group.
The App configuration policies do not interact with the deployment policy. The Microsoft 365 Apps deployment provides the installation of the office suite. Any pre-configured Outlook server settings etc., are provided through their own configuration policy which is created and assigned separately.
When a Microsoft 365 application does not install properly on a managed device, a technician should review the device install status of the app in Intune for both the status and error code for that device; subsequently verify if that device is contained within the assigned group. Technicians should also determine if an older version of Office is present since Remove Other Versions determines whether an older version is removed.
