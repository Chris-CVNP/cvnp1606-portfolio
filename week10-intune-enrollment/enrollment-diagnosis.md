**State**
AzureAdJoined = Yes. This indicates that the user has logged in successfully to their Microsoft Entra account and that the OS-level Entra Join completed. Also, since WorkplaceJoined = No, the user did not register a work account using Microsoft Entra. Additionally, DomainJoined = No indicates that the computer is NOT connected to your company's local Active Directory. As such, this is a Cloud-Only Join, not a Hybrid Join, and therefore, there can be no policies applied from your local AD environment. Lastly, MdmUrl is empty; as such, the second part of the MDM/Intune integration failed completely. Therefore, this machine will not show up in the Intune Console, nor will any policies be able to reach it.
**Root Cause**
The primary reason MdmUrl is empty is due to the fact that you have not enabled Auto-MDM Enrollment for this user. Most likely, the MDM User Scope is set to None or is set to apply to some Group that the User is not a member of. As long as the User remains outside the bounds of the MDM User Scope, the computer completes the Entra Join process, and then is never passed over to Intune.
**Remediation**
First and foremost, we need to verify the MDM User Scope setting within the Intune Admin Center under Devices > Device Onboarding > Enrollment > Windows Tab > Automatic Enrollment. We want to ensure that the MDM User Scope is set to All OR to Some with a Group where the User belongs and save those changes. Furthermore, in addition to having an Intune License assigned to the User in the Microsoft 365 Admin Center under Users > Active Users > Select User > Licenses and Apps Tab, we must also confirm the Tenant has a Microsoft Entra ID P1 or P2 Subscription.
**Verification**
From a client-side perspective, I would use dsregcmd /status to verify that AzureAdJoined = Yes AND MdmUrl = https://enrollment.manage.microsoft.com/. From a portal-side perspective, I would navigate to the Intune Admin Center under Devices > All Devices > Search for Computer Name > Verify that it says Managed By Intune AND that it has had a Recent Last Check-In Time.
